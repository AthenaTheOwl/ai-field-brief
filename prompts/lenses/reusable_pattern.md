# Lens: Reusable Pattern

Convert this source into transferable patterns.

For each pattern:
- name
- mechanism
- where it transfers
- where it does not transfer
- source refs
- confidence

Avoid generic patterns such as “use AI more.”

Read `prompts/editorial_contract.md`. Separate the source's tested setting
from the proposed transfer. Name the assumption the new setting must
share and a cheap comparison that could show the transfer fails.
