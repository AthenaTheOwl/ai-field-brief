# Lens: Governance Surface

Map the source to governance implications.

Read `prompts/editorial_contract.md`. Distinguish a declared permission
from runtime enforcement, a signed assertion from an executed action,
and a proposed rule from one already in force. Name the check each needs.

Consider:
- auth and identity
- approval flows
- audit logs
- tool permissions
- data boundaries
- memory/promotion policy
- deployment safety
- runtime snapshots/replay
- blast radius
