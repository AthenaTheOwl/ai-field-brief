# Lens: Mechanism Extraction

Identify the mechanism underneath the source.

Ask:
- What changed?
- What system behavior does this reveal?
- What causal mechanism is being proposed?
- What evidence supports it?
- What is still missing?

Return only mechanisms that can be linked to source spans.

Read `prompts/editorial_contract.md`. Trace the steps from changed input
to reported outcome. Name a competing explanation and what the source
holds fixed. Mark untested causal steps as hypotheses.
